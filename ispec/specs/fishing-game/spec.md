# OceanAngler 产品合同

### Requirement: REQ-01 儿童钓鱼完整循环
The system SHALL satisfy the P0 contract: 能从抛竿完成至放流并再次抛竿，20次无卡死。

#### Scenario: REQ-01 acceptance
- **WHEN** 对应阶段执行验收
- **THEN** 必须提供以下证据：能从抛竿完成至放流并再次抛竿，20次无卡死，未运行不得写 PASS。
