# Build 6 设备复核

OceanAngler 0.1.0 (6)，最低 iOS/iPadOS 17，仅本人授权账号的内部 TestFlight。准备检查已通过：完整60项Editor、20项无画面PlayMode及11项发布保护；其中完整成长34轮与连续20轮、场景重建恢复分别通过，见[准备回执](../reports/beta6-preparation.json)。生成场景20对象归一后与dbea631一致，平台构建号改为6。冻结、归档、上传、Apple处理、分组与实际安装须以各自回执为准。

本次累计纳入 build 5 之后的沉浸式页面层级、底部收鱼信息、任务/钓具反馈、陆坡独立环境候选、鱼体眼口及薄鳍、钓组滚轮/绕线/主轴、移动 HDR 与 4×MSAA 启动适配。三海域、英雄鱼与首套钓具仍为候选；其他鱼种、钓具及观察生物仍有样板，不能视为完整拟真美术验收。

更新同一应用，不卸载或清档。先记录现有积分、鱼获、图鉴、观察记录、任务、装备与音频/左右手/减弱动态设置，更新后重开核对。继续读取旧 schema 1/2，首次记录保护观察仍升级至 2；旧 build 4 不兼容 2，不以清档降级处理。

1. 首页进入海域装备准备，出发按钮应固定可见；游玩只保留暂停、阶段动作和必要仪表。图鉴、任务、设置与钓具从页面进入，中文短标签与图形一致，左右手均能操作。
2. 按住抛竿或收线时进入菜单、后台或锁屏，持续输入应取消；返回保持暂停，主动继续才恢复。统一结束确认可取消并回到原状态，确认后回准备，不重复结算。
3. 正常完成抛竿、等咬钩、提竿、控线、收鱼、记录并放流；收鱼底部文字不挡鱼体，按钮可点击。检查近看钓组、试摇、旋转、全竿和返回；鉴赏不增加奖励或推进钓鱼。
4. 自然解锁并往返三海域、阅读图鉴长文、滚动任务与钓具、记录保护观察；观察不增加鱼获或积分。不得注入个人成长以替代验证。
5. iPhone/iPad 各连续运行 20 分钟，记录帧耗、内存、温升、听感、后台/锁屏与重开恢复。儿童首鱼三分钟及张力理解、图标理解、科学/用户/美术 A1–A3 分别观察。

模拟器与程序 EventSystem 通过不代表真实系统触摸、儿童体验或真机性能。安装需明确来自 TestFlight，核对版本 0.1.0、构建 6 和实际主界面；API 分组不证明已安装。原始日志、设备标识和个人截图留在本机忽略目录，公开报告脱敏。
