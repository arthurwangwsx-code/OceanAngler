# 水面抛竿与水下观察

REQ-03/05/06/08后续，实施IN_PROGRESS。当前游玩钓具根部y=-0.3，低于海湾4.5米水面，深水海域也复用这个位置。虽然钓组机械结构可动，整套钓具沉在海底并不符合钓鱼呈现。原抛竿轨迹也直接终止在水下拟饵点。

本轮把实际钓具放到各海域水面上方，保留真实导环/摇柄/线杯/滚线轮与嘴部连接。抛竿结束点为同一海域水面，等待阶段才下沉到既有鱼群空间；鱼体路径、积分、随机选择和落盘规则保持。三海域的时空仍是游戏演绎，深海下沉时间经过压缩，不冒称真实流体或绳索物理。

主游玩准备/蓄力/抛竿使用水面视角，落水后切入既有水下观察。短暂海色淡出/淡入承接切位，避免镜头快速穿越200米水层；菜单、失焦和暂停保留既有输入保护。设置增加“固定水下镜头”，减弱动态时也使用固定水下镜头；无新增常驻游玩按钮或信息面板。放流动画结束后才返回水面，避免截断离开动作。瞬时过渡与普通HUD占用分别记录，不把过渡遮色算成海洋美术已合格。

验收检查实际三海域/左右手钓具与水面关系、抛出/落水/下沉端点连续性、嘴外线段与实际英雄鱼网格、镜头可逆/设置持久化/减弱动态/菜单与暂停恢复，以及真实导入原图和双端原生正常流程。头部无画面检查、离屏GPU、模拟器、用户美术、儿童和真机分别验收。仍受首套样板审阅门约束，不批量制作其余鱼种，不更新已发TestFlight8。

淡入绘制依据[Unity 6.3 GUI.DrawTexture](https://docs.unity.com/en-us/engine/6000.3/script-reference/unityengine/gui/drawtexture)的透明混合契约，仅过渡期间绘制海色，不接收输入。
