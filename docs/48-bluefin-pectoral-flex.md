# 蓝鳍鲹胸鳍分段弯曲候选

对应REQ-05、2.4／2.7。当前胸鳍沿原根骨整片摆动，细长鳍面缺少相对鳍根的弯曲。此次继续首条鱼的制作，保留三LOD静态几何、UV、九贴图、鳃盖／眼口、原12骨静态矩阵与七动作原曲线，不批量制作其余物种，也不修改钓鱼规则、积分或游玩HUD。

参考[Alben、Madden与Lauder的鱼鳍形状控制研究](https://public.websites.umich.edu/~alben/RSIF20060181.2.pdf)：研究通过蓝鳃太阳鱼鳍条实验和力学模型讨论曲率控制。这里只采用“鳍条／鳍面可以弯曲”的定性启发；实验物种不是蓝鳍鲹，不外推其参数、曲率分布或精确游动方式。以下波形、幅度与绑定是原创美术候选，不是Caranx melampygus的生物力学测量；资料图片不进入游戏或公开资产。

计划为每侧增加Mid／Tip两个控制，总16骨；在现有胸鳍根之外渐变绑定鳍膜和实体鳍条。根部径向四分之一仍完全随原根骨，单顶点最多四权重，面数预算保持25000。七语义分别设置温和弯曲和相位滞后，周期值／切线一致。原根骨动作仍负责整体摆动，新控制负责鳍面相对根骨的变形；源和实际导入都要通过“固定根姿态，比较打开／关闭新增控制”的消融，不把控制骨存在或整体转动当作可见变形证据。

先保存旧源参考并测量旧模型在移动根坐标系中的远端非刚性位移，保留真实红测；新源逐项比对全部静态几何／UV／材质角色、非胸鳍权重、原骨与原动作。检查重复编辑不累积权重、根部不漂移、鳍膜和鳍条共同变化、三档低LOD、实际运行时动作与暂停／减弱动态。Unity再烘焙图鉴动画包络，原材质绑定、画框边距和拟真标准不放宽。

GPU采用生产Medium、Metal、Half HDR与4×MSAA，保留初次／重复图及失败；离散取样和视频采样率不作为运行FPS。原生模拟器另外检查自然播放、可见暂停／继续和旧进度保护，实际查看画面。TestFlight 9及其源码冻结保持独立，新候选的本地构建号相同不代表已上传或替换正式发行包。用户／科学／儿童、最终美术与真实双设备20分钟继续独立验收。

2026-11-25贴合红测：初版保持全部静态几何的16骨候选虽然通过288项源检查、85 Editor及5 Play，独立鳍条中心对实际变形鳍膜BVH的检查仍有41/42失败。七动作×三LOD×两侧、每项八姿态中，最差新增分离43.54mm，远档原膜只有径向首末两排，不能承载中途弯曲。这些通过不能代替组织贴合，初版不进入新原生包。

据此调整内部实现约束：只为胸鳍薄膜增加0.25/0.50/0.65/0.75径向切分，沿原三角面插值，保留每个原顶点和原表面；全部其他多边形、实体鳍条、鱼体/眼口/鳃、原UV、九贴图及原12骨/七动作仍保持。总25000面上限、0.4mm新增分离阈值和真实渲染要求不放宽。额外用原始保存Blend独立比较受保护面、原顶点、膜表面距离/面积及逐角UV，不能只凭作者报告接受网格变化。修复和重新导入/渲染尚待通过。

第二候选膜细分后为24748／10688／4908面。独立源比对309项通过：原顶点和全部胸鳍膜外面完全保持，新膜相对原面最大距离约0.027微米、逐角UV误差小于0.0000016。首次辅助器在薄且近共线的膜边使用float32 BVH/重心坐标出现假差异；保留失败，改成BVH仅筛候选、float64逐三角形最近点/UV计算，同一0.3微米表面及0.000003 UV门槛不变。新的原始基线由修改前保存Blend独立读取，无作者生成数据替代。

进一步把贴合采样扩至实体鳍条每段的1/4、1/2、3/4处，发现第二候选仍最大新增约2.13mm分离，39/42失败。原动作/12骨不动，将四新增控制的峰值角整体改为初版15%，最大Mid峰值0.018弧度；这是原创温和运动候选，不是科学参数。0.4mm贴合门槛、源远端至少2mm真实非刚性变化、Editor至少0.5mm世界位移消融及GPU至少20像素变化保持，避免用不可见动作“通过”。第二候选选定源/导出/配方已单独保留；第三候选还需全部重新验证。

第三候选源309项/42项组织贴合及85 Editor通过；源各动作/LOD/侧远端最大非刚性位移的最小值7.22mm，最大新增组织分离0.262mm。随后Play真实控制器1/5失败：idle胸鳍Tip在两时刻均为同一角度。实际导入动画只有0、1.633、2秒三关键帧，仍启用FBX简化0.5和Unity KeyframeReduction/0.5度容差。只比较姿态与bind-pose的消融不能保证细微动作正确随时间播放；失败保留。

按[Unity动画压缩API](https://docs.unity3d.com/cn/6000.0/ScriptReference/ModelImporter-animationCompression.html)及[Off枚举](https://docs.unity3d.com/kr/current/ScriptReference/ModelImporterAnimationCompression.html)，本模型导出取消关键帧简化、BluefinAssetBuilder设置动画压缩Off，并重新生成实际七运行时Clip/图鉴包络。源十二骨原曲线仍须独立保持，实际导入的重采样和数据量会改变；其他鱼与模型的导入设置不变。原Play阈值不下调，完整源/Editor/定向Play/GPU重新验证后才冻结新Simulator候选。

取消简化/压缩后，实际idle Tip已为61关键帧（原三帧），源309/贴合42及全85 Editor重新通过。后续Play在进入idle状态前失败（与前次Tip不动是不同前置失败）；保留原结果，改为2秒上限等待实际语义状态且转场结束，再覆盖1秒内10次自然更新，而非假定首帧0.25秒足够。小角度用逆四元数差的double atan2测量，避免float点积acos舍入为零，原0.01度播放/0.001度暂停阈值保持。无生产控制器/时间/动作幅度变更，重新跑相同五个定向Play；不把前次失败改成通过。

当前源与导入工程PASS：原参考309项、42项有限组织增量贴合、85 Editor及最终5项定向Play通过；0.00675～0.018弧度Mid峰值，16骨，24748／10688／4908三角面。iOS目标Metal、生产Medium/Half HDR/4×MSAA的84视角（7动作×3LOD×两时刻×两侧），336张active/held的首/重绘图通过：全部重复差0，最小消融4368像素，最小视口边距12.93%。六张接触表含84 active及42 held图、两张原尺寸图已实际查看；反侧偏暗限制细部判断，未见本轮采样裁切或明显新增裂缝，但鳃缘、塑料感、整体自然外观仍不合格。

贴合结果只量“在原静态距离之上的新增分离”，不代表所有静态鳍条/膜绝对零间隙，也不是连续全表面碰撞证明。0.262mm为原始源美术单位下的测量，不外推实际鱼类生理参数。原生Simulator尚待重建，TestFlight 9保持原冻结。两次共享空间准入因另一登记工程的du扫描30秒超时而未启动作业，之后仍以相同14 GiB预算/120 GiB底线恢复；未绕过入口、修改共享策略或终止其他任务。
