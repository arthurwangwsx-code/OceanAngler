# 庸鲽长鳍运动候选

对应4.9/4.10与REQ-05。当前长背鳍和臀鳍只沿用身体权重，虽有整体弯曲，缺乏独立边缘运动。本轮为既有候选补动画并修正后半身蒙皮，不批量制作其他鱼，不更改模型几何/UV/PBR、口腔/牙龈/鳃盖/双眼、钓鱼规则、积分或游玩HUD。

参考[Greaves 2001博士论文第27页表2.2，PDF第43页](https://theses.gla.ac.uk/76185/1/13833902.pdf#page=43)：养殖幼年大西洋庸鲽的悬停观察包含背鳍、臀鳍与尾鳍的轻微摆动，巡游还记录胸鳍参与转向。这里只据此避免把长鳍始终做成刚片，不据此推定成年野生鱼的精确频率、幅度或所有游姿。论文与页面图仅私下研究，不随游戏分发；本轮波形参数是美术候选，科学审校仍待完成。

两侧各17个分段控制，新增34骨，总42骨，每顶点最多4权重。根部内侧四分之一保留原身体绑定，向外平滑增加鳍控制，最外缘保留2%身体影响以支持重复编辑。分段控制随原身体骨架，波向头至尾传播，约1.1个空间周期；七个动作分别调整幅度与时间周期，端点与切线周期一致。胸鳍与尾鳍仍保留原动作，不以本轮长鳍修正宣称全部游动已拟真。

低LOD若某个外侧顶点原有超过两个身体影响，仅在需要新增鳍控制的外侧保留其中最大的两个再归一，以满足四权重预算；根部不重写。实际数量记录在源工程制作回执，不隐瞒由此带来的远距形变差异。

保持三LOD20784/8312/3117三角面与原几何/UV/材质身份，不重跑拓扑生成或低LOD减面。原八骨和七套身体/下颌曲线保持，新控制只写两侧长鳍。图审另发现旧下颌权重函数把后半身蒙皮也绑在头骨：原LOD0尾段2464顶点仅跟随head，swim/burst/hooked中位移为0，长鳍根与躯干分离。本轮有意仅把Skin材质、X>−0.55的顶点改为原身体骨链插值，保留前端口腔/眼睛及其他鳍权重；旧“非鳍权重全部不变”的范围据此收窄为前端和其他鳍不变。除固定身体后的鳍控制消融外，新增真实躯干位移及130对鳍根中心在变形鱼身内的检查，避免只验证骨控制而漏掉实际接缝。比较关闭新控制而保持同一身体姿态的实际蒙皮，检查鳍根、鱼身、薄壳厚度、相位传播，避免把整体摆动误算为独立鳍波。先捕获旧源基线和红测，再检查新保存源、实际Unity导入、GPU画面及原生运动，分别报告实现与验收。

`python3 tools/art.py build --asset halibut --fin-motion-only --label <fresh-label>`可更新既有源；完整生成器也调用同一动画制作步骤。额外验证入口为`tools/art_validate_halibut_fin_motion.py`，需先在旧源上用`--record-reference`留基线，再以`--reference`检查新源，输出到不同`--output`目录。基线不是验收。成品A1–A3、用户/科学/儿童与真实设备继续独立验收，不能凭骨数、周期或测试通过宣称自然。
