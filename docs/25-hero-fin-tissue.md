# 英雄鱼薄鳍与材质制作约束

对应 REQ-05/任务2.5，继续制作首条蓝鳍鲹样板，不批量制作其他物种。本次迭代前模型的鳍膜为不透明近似，近景有厚塑料感；这次改进真实网格厚度、独立鳍条和鳍膜表面，不能把图鉴文字或更换拍摄背景当成模型改进。

结构与鳍色参考仅用于观察：[日本国立科学博物馆标本页](https://www.kahaku.go.jp/research/db/zoology/Fishes_of_Andaman_Sea/contents/carangidae/18.html)、[澳大利亚博物馆物种页](https://australian.museum/learn/animals/fishes/bluefin-trevally-caranx-melampygus-cuvier-1833/)。不下载、再分发或取样机构照片。透明度、厚度和 PBR 数值均为作者的实时表现选择，未经生物测量或科学人工认可。

保留已有体形、12骨骼、七动作、口部/眼部修正与 25000 三角面候选预算。鳍膜保持闭合薄壳，在根部至末端渐薄；新增原创粗糙度/法线及 RGBA 膜图，不能只给整条鱼降低不透明度。实体鳍条与膜分成两个材质，鳍条仍是不透明实体并保留阴影，身体/口腔/眼睛不能变透明。源检查须读取保存网格和纹理，检查真实壁厚、鳍条/膜归属、UV、权重与姿态；预期参数不能替代实际测量。

Unity 使用现有 URP Lit 的透明表面与保留高光的混合设置，调用安装版本提供的材质状态设置接口，不复制包源代码到项目。参考 [URP 透明混合说明](https://docs.unity3d.com/cn/current/Manual/urp/prebuilt-shader-graphs-urp-lit.html)。真实透视背景须在渲染图中出现；透明排序、重叠鳍、双侧与极斜视角必须检查，不能用发光伪造透光。膜不写深度、实体鳍条写深度并投影，透明膜的阴影与折射是独立限制，不据此声称完整物理光学。

原六槽增加为七槽是为分离实体鳍条与透明膜，属于明确的绘制成本；纹理、材质、三 LOD 与实际帧耗分别记录，不放宽几何预算。源工作室、Editor Metal 与手机/平板原生画面分验，保留失败及前后对照。薄鳍不新增操作入口或改变积分/存档格式；原生实图发现旧收鱼卡遮住背鳍，另按沉浸要求收进底部提示区，并把收鱼与未标记的可见背景纳入覆盖检查。完整 A1–A3、科学/用户/儿童、其他成品物种与钓具、最低系统和双真机 20 分钟仍是独立出口。
