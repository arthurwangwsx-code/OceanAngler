# 深水近景照明

对应 REQ-06 与任务 4.10。4418971 原生控线及放流已显示扁鱼完整体形，但鱼体仍过暗。固定 ResearchCameraFill 位于旧平视镜头附近，强度 6、偏蓝、朝向远处海床；不随新镜头照亮眼侧。当前只改善探索视野，不声称真实深海光学模拟或最终美术通过。

复用这盏已有研究相机灯，不增加灯数或游玩 HUD。它从最终镜头右上方稍偏移，朝镜头前方近景照射，使用中性偏暖色和短距离光束；海雪、深蓝雾、原有潜器暖灯、太阳衰减与环境光保持。水面关闭，离开海域恢复场景基线，暂停与减弱动态不引入新的自动运动。最终相机包括扁鱼斜俯视、图鉴和保护观察的调整。

使用 URP 原有逐像素附加灯与每对象 4 灯预算，场景仍为 3 盏无阴影聚光灯，不增加附加阴影或全局曝光。配置与 [Unity URP 灯光限制](https://docs.unity.com/en-us/engine/6000.3/manual/lighting-overview/lighting/light-limits-in-urp)一致；具体强度由同姿态实际渲染判断，API 参数本身不构成可读性验收。

分别检查三类证据：生命周期/暂停/相机关系的 Editor 与 PlayMode；同姿态、同材质、同雾的旧灯/新灯 Metal 对照和首绘/重绘；新源码原生包的双端实际控线/放流及存档保持。离屏对照没有游戏 UI，不代替原生；亮度统计不代替眼睛、花纹、鳍缘和整体观感人工审阅。模型、贴图、规则和存档格式保持；自然鳍波及最终美术/用户/科学/儿童/真实设备仍分别验收。
