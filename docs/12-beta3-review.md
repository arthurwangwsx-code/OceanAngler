# Build 3 设备复核

适用于 OceanAngler 0.1.0 (3)，冻结源码05c8cc7cd5abf747e6a174cc154e4f575e35e422。Apple处理及本人组以[发布回执](../reports/testflight-0.1.0-3.json)为准；设备实际安装和运行另验。最低iOS/iPadOS 17。首鱼、首套钓组、首海湾仍为美术候选，其他模型/海域仍是样板，观察生物尚未进入场景。

## 更新前后

1. 若设备已装build 1或2，先记下鱼获数、积分和当前装备；通过TestFlight更新到0.1.0 (3)后核对，不清除个人存档。首次安装则记录设备型号、系统和能否进入钓鱼主界面。
2. 检查首次进入时鱼的眼睛、鱼鳃、鳍和身体颜色；打开图鉴、切换鱼类再返回，观察是否出现只在首次显示的异常。离屏诊断通过不能代替这一项。
3. 完成抛竿、提竿、控张力、收鱼及记录放流；记录成功后应先转向再游离，竿恢复空载。中途打开图鉴或暂停再返回，不应自动收线或重复加分。

## 本次重点

- 图鉴：已发现鱼显示颜色，未发现鱼保持轮廓。查看学名、个人记录、辨识和自然环境，滑到底部；选择大西洋庸鲽检查长学名。旋转、放大、静止后点击重置；重置恢复视角与游动，浏览不增加鱼获或积分。
- 海湾：在海域与装备进入看看海湾，检查水面倒影、船舱、水位边缘、沙地、礁石；切换水上/水下和观察角度。返回应保持暂停，主动继续才恢复。
- 钓具：观察入门钓组，检查九个导环、鱼线、竿弯曲、摇柄/转子/线杯；停止演示和离开页面后机构应停止。
- 任务：阅读18项完成方法，完成一次鱼获后核对进度；游戏中的物种海域与数值不能当作现实分布或捕捞建议。
- 声音：音乐默认关闭。分别开关音效/环境声与探索音乐，返回出海并继续后试听；暂停和后台时停止，主动继续后恢复。听感、耳机与设备触觉分别记录。
- 恢复：退后台、锁屏、恢复、重开后核对鱼获、积分、装备和音频设置。只做本人可控的测试，不删除个人存档或绕过系统权限。

## 验收记录

每项分别写PASS、PARTIAL、FAIL或NOT_RUN，并注明构建号、设备/系统、发生页面和复现步骤。原始截图、设备标识及日志保留本机，不公开上传。

iPhone/iPad各20分钟的帧耗、内存、温升、后台恢复、实际触控；连续20次钓鱼；儿童/家长首鱼3分钟及张力理解；A1–A3美术、科学人工审阅均为独立门槛。首轮操作通过不代表完整产品通过。
