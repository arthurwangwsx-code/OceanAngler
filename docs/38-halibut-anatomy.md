# 大西洋庸鲽解剖候选

本页与 halibut-anatomy 报告保留第一轮隔离候选的历史结果。当前口部修正及生产选鱼/图鉴接入进展见[后续记录](../reports/halibut-mouth.md)；第一轮口部失败未删除，不能当成当前资产仍未接入的依据。

本轮针对图鉴中“大西洋庸鲽仍呈普通鱼形”的明显缺口，制作一条独立候选。没有获得首套美术方向的用户批准，不据此批量制作其余物种，也不把它标为成品。完整产品和 apply 继续未完成。

## 形体依据

[NOAA](https://www.fisheries.noaa.gov/species/atlantic-halibut)与[加拿大 DFO](https://www.dfo-mpo.gc.ca/species-especes/profiles-profils/atl-halibut-fletan-atl-eng.html)的物种文字资料用于核对右眼型扁平体形、大口、弯曲侧线及内凹尾缘。候选的两眼位于朝上的眼侧，浅色盲侧朝下。资料仅作为形态依据，专家科学审校仍 PENDING；没有复制参考照片或绘图。

几何、UV、程序 PBR、骨骼和七动作均由本项目原创。可编辑源、工具与权利边界见[源资产说明](../art/source/halibut/README.md)。

## 本轮交付与边界

- 三 LOD 实际为 20336 / 8134 / 3049 三角面，约 100% / 40% / 15%。身体图 1K、鳍图 512、虹膜 256，保留非金属粗糙度、法线及 URP 打包贴图。
- 独立横向扁体、眼侧双眼、浅腹、连续边鳍、凹尾、口内空间和颌骨。七动作与源文件内骨骼可编辑；并不声称已达到自然运动或最终解剖质量。
- Unity 生成材质、三 LOD prefab、七动作播放资产和随颌移动的钩点，沿用现有 AuthoredFishVisual。
- 本轮保持实际遭遇、图鉴的选鱼工厂和游戏 UI 原样，候选仅供隔离审阅。接入前还要确认图鉴俯视构图、实际钩线、收鱼/放流、双端模拟器显示和存档保持。

## 失败样本与验证

第一次源检查发现减面 UV 越界。距离 LOD 现在记录减面原始越界幅度，再约束回同一图集；没有放宽有限/范围检查。第一次源渲染因三 LOD 同时可见而重叠，俯视还裁尾；修正源可见性和机位，旧图保留为失败样本。

第一次 Unity 测试有三项失败。实际 FBX renderer 缩放为 100，测试对默认 BakeMesh 快照再应用 TransformPoint，重复缩放了坐标；现显式补偿缩放，并检查归一模型长 2.3–2.6、体宽 1.0–1.3 的世界单位范围，不把该比例当作所有鱼获的实际尺寸。循环检查仅针对有变化的曲线，避免把范围低于 1e-6 的静态数值噪声当作动作；游动以多个相位在世界单位下检查，不用单个相位代表全动作。[Unity BakeMesh 文档](https://docs.unity.com/en-us/engine/6000.3/script-reference/unityengine/skinnedmeshrenderer/bakemesh)和本机实际结果均保留为依据。

第一次 Metal 图的眼部特写机位位于错误一侧，只拍到皮肤；该图不作为眼部审阅通过。修正机位后重新捕获。详细结果及原始范围见[本轮记录](../reports/halibut-anatomy.md)和[结构回执](../reports/halibut-anatomy.json)。

## 未通过项

眼部、鳃盖、口缘、鳍连接和皮肤仍偏简化。开口近景中口缘/牙根连接缺失、牙齿呈脱离感，该项视觉 FAIL，必须修正后再接入游戏。鳍波与身体运动的自然感、美术 A1–A3、用户和科学审阅未通过。本轮没有新 Player、个人手机操作或 TestFlight 发版，不能引用旧双端成长结果作为此候选的验收。儿童操作、实体触控、最低系统和真实双设备 20 分钟仍待验。
