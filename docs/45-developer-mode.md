# 本人测试用开发者模式

承接用户2026-11-25新增要求：本人测试时可体验全部功能，不受积分门槛限制。家长区提供明确入口和独立确认页，开启后全部三海域、二十件钓具及三种保护观察可直接使用；图鉴、任务、两档辅助和设置同样可访问。模式不伪造积分、鱼获或任务完成，钓鱼和记录仍走真实玩法。

正常进度与开发者测试进度分文件保存。开启开发者模式仅更新测试文件，关闭后读取原正常文件；重新开启恢复测试进度，重启保持上次选择。开发者文件采用单独的存档信封版本与角色标记，模式选择也参与校验；正常读取器不能将它当作普通存档。原有普通载荷与校验保持兼容。

切换前停留暂停状态，由独立确认页说明会结束当前尚未记录的鱼获。写入成功后才替换当前进度并回到准备页，保持暂停；写入失败保留当前模式、未完成鱼获与正常文件。测试文件损坏时保留原件，回到正常模式并提供家长区明确重建入口；重建仅作用于测试进度。正常模式原积分限制继续有效。

模式标识放在首页、准备及家长页面，不增加常驻游玩HUD。沿用真实安全区、至少44点触控和可读字号。单独验收零积分的全海域/装备/观察、取消与切换、重启、保存失败和双进度隔离，再以模拟器实际页面验证。模型、真实触控、儿童与完整产品仍按原验收目标推进。

入口：首页／暂停 → 设置 → 家长区与隐私 → 家长验证 → 开发者模式 → 开启 → 确认。在普通发布构建同样可用，不依赖Unity Development Build。正常文件ocean-progress.json；测试文件ocean-developer-progress.json。后者v2信封绑定角色与选择位，前者保持v1和原始载荷校验兼容。
