# Build 4 设备复核

适用于 OceanAngler 0.1.0 (4)，最低iOS/iPadOS 17。源码已冻结于ee7ba501a8922b01bffe2cb60fd4f793e3b5914e；Apple处理、本人内部组及测试说明已通过[发布回执](../reports/testflight-0.1.0-4.json)核实，实际安装启动仍未验。首蓝鳍鲹、首纺车钓组及首海湾仍为美术候选；其他11物种/两海域仍是样板，保护观察模型与交互尚缺。

## 更新与存档

使用本人授权的TestFlight账号（包括arthur.wang.wsx@gmail.com）。如已有build 1–3，先记下积分、鱼获、装备和设置，通过TestFlight更新后核对；不删除个人存档。首次安装记录设备型号、系统、所装构建号，以及是否看到钓鱼主界面。账号已分配不能代替实际安装证明。

## 本轮重点

1. 首次显示、图鉴切换鱼类及返回主界面：比较鱼体颜色，检查鳍、嘴、眼睛和块状阴影。当前参考图来自Editor离屏，需在设备重验；不要把候选质量记为拟真美术通过。
2. 完成选装备、抛竿、等待、提竿、控线、收鱼、记录和转向放流。观察拟饵与嘴部、鱼线与钓组的连接；记录成功前保持鱼获，成功后只结算一次。失败重试和连续20次实际UI操作分别记录，不使用规则模拟替代。
3. 在等待、控线与收鱼时暂停、查看图鉴、返回或退后台；返回保持暂停，主动继续才恢复，避免重复奖励或丢进度。减弱动态模式另测。
4. 海湾三条环境鱼应独立游动，不进入鱼获/奖励。观察水上/水下、礁石、岸线、船舱及倒影，检查明显穿模。环境鱼复用首鱼，不代表新增三种鱼。
5. 查看图鉴学名/辨识/栖息环境，长文字滚动到底并重置视角；图鉴阅读不增加积分。任务与装备成长、音效/默认关闭的音乐及其独立设置继续回归。

## 设备与完整产品

iPhone和iPad各连续20分钟，记录流畅度、内存、温升、锁屏/后台恢复、横屏安全区与实际触控。阴影软过滤和较大鳍贴图的设备成本尚未测量。儿童/家长首鱼3分钟、张力理解和20次UI循环，美术A1–A3、科学人工审阅、听感/触觉均为独立门槛。

每项记录PASS、PARTIAL、FAIL或NOT_RUN及构建号、设备/系统、页面、复现步骤。原始截图、设备标识和日志只存本机，不公开。完整产品仍PARTIAL。
