# 产品方案 v0.1

## 定位与目标
内部代号 OceanAngler，中文暂名海洋小钓手。为约 6–12 岁儿童及陪伴家长设计：在明亮、拟真的海洋里学会钓鱼，认识鱼类，积累探险记录。年龄是设计假设，最终商店分级按实际内容问卷确定。首发 iPhone/iPad 横屏；共享 UI 和玩法，iPad 利用空间扩大场景与图鉴，不建立第二套产品。

核心承诺：容易学会、每次出海有收获、鱼与工具确实是 3D、可近距离欣赏。真实形态与材质，温和色彩和节奏；不用夸张卡通鱼替代真实鱼。深海是成长后期海域，前期从浅海开始，避免全程黑暗与恐怖。

## 核心循环
选海域 → 选钓组 → 观察鱼群/水层 → 短按或蓄力抛竿 → 等待咬钩 → 提竿 → 按住收线、松手降张力 → 收鱼展示 → 记录尺寸/新物种 → 放流得积分 → 解锁钓具和海域。
一次捕获目标 45–120 秒，探索一局 5–10 分钟，可随时暂停退出。首次教学目标 3 分钟内完成一条鱼。所有时间为待儿童试玩校准的设计目标。

初学模式：引导鱼必定在 3–8 秒内咬钩，提竿提示至少 3 秒，过张力自动松线救援；只减本次技巧奖励，无付费补救。标准模式：天气、水层、拟饵、提竿时间和控线影响成功。两模式共享内容，模式记录分开，辅助不会阻止图鉴收集。

## 功能与页面
2026-11-24 界面约束：实际游玩以沉浸为先。海域/装备移到独立准备页，首页/暂停菜单承接图鉴、任务与设置入口；详情有上一级返回，结束本次探索使用统一确认页。游玩不常驻完整导航、研究积分、装备介绍或大块信息面板。边缘仅放暂停与主要动作，收线阶段才显示小型张力/进度，普通 HUD 安全区占用目标不超过 15%。中央观察区保持无遮挡；原创形状图标配中文标签，至少 44 点触控，支持左右手。此设计要求的实现和模拟器证据独立记录，不能据此推定儿童/真机验收。

启动首页呈现上次海域、继续出海、鱼类图鉴、钓具库和设置。出海准备提供海域深度与目标鱼提示，装备槽为竿/轮/线/饵；不可用组合解释原因。主钓鱼页中间为 3D 场景，边缘仅显示暂停与单一主要动作，任务和积分移至首页/暂停菜单；咬钩用形状、声音与文字一起提示。张力条有安全/警戒形状标记，不能只靠红绿颜色。

镜头包含船上/码头视角、水下观察、收鱼近景；切换平滑且可关闭自动切镜。模型鉴赏支持旋转、缩放、暂停动画和重置视角。鱼类图鉴显示中文名、学名、栖息水层、尺寸记录、原创简短知识；未发现鱼显示轮廓且不收费解锁。钓具库展示真实结构、用途与比较。任务页提供探索、技巧、环保三类固定目标，完成不受日期限制。

设置包含音效/音乐/触觉、辅助强度、左手模式、减弱动态效果、文字尺寸、家长区、清除存档与支持联系。家长区放外链、隐私说明及二次确认的清档，需成人操作门槛。暂停、失焦、中断、锁屏时取消持续收线并冻结模拟；恢复先显示继续界面，不自动抛竿或扣资源。

## 儿童体验与商业边界
首批离线，无账号、定位、麦克风、相机、广告、分析 SDK、内购、排行榜或开放聊天。没有体力、付费抽奖、每日签到惩罚、倒计时促销或装备永久损坏。鱼被记录后放流；无血腥、剖鱼或残酷挣扎特写。鲸豚、海龟等观察对象不进入可钓鱼池。每次 15 分钟温和提示休息，不阻断存档。

## 范围
P0 技术切片：1 个海湾、3 种原型鱼、2 套钓组、完整捕获与积分/存档循环。P1 首个完整离线版本：3 个海域、12 种可钓鱼、3 种仅观察生物、6 根竿/4 个轮/4 种线/6 种拟饵、18 个固定任务、图鉴、教学、家长设置。P2 扩展至 5 海域、24 鱼种、深海光照和观赏水族箱；多人和云存档不属于首版。

## 产品验收
首次试玩至少 5 组儿童/家长，在家长同意且不采集个人身份的条件下观察：至少 4 组能在 3 分钟内完成首鱼、解释松手降张力，并找到图鉴。连续 20 次捕获无卡死；成功或逃脱都可重新抛竿。双设备适配与美术验收独立，不以流程可玩证明模型已拟真。
