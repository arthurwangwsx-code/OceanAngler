# 蓝鳍鲹连续鳃缘候选

承接REQ-05与2.4，完整产品、美术和用户/科学审阅保持PARTIAL。本轮只处理鳃盖边缘在近景中的断续点状观感，不批量制作其余物种。上一轮页面、输入、进度和原生证据保留各自冻结范围。

现有鳃缘为半埋入数学鱼体表面的细管；实际三角网格与该理想曲面不完全重合，管面可能被鱼体间歇遮挡。先保存原源文件、非鳃缘表面/UV/权重、12骨七动作和九PNG摘要，并用真实网格射线检查旧状态，再决定制作参数。保留原三档其他网格，避免全量重生成导致减面身份变化。

候选以实际鱼体三角形裁出连续窄面，使用同一鳃缘材质槽、实际表面UV和插值骨骼权重；边缘的宽度、抬升量和轮廓为原创美术选择，不声称生物测量值。检查可见面是否被鱼体遮挡、两侧连通性、动作后贴合、三LOD与既有预算。源文件棚拍、Unity导入/GPU、原生及用户审美分别验收，不能只凭射线检查宣布拟真。
