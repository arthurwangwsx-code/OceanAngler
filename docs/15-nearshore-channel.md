# 近海航道候选

对应REQ-06，第二海域候选已接入，完整产品与美术仍PARTIAL。目标是把第二海域从运行时基础几何推进为独立Blender/FBX/PBR/三LOD场景，并复用共享水面与观察界面；不是现实地点或生物共存关系的还原。

构图为开阔深水通道、三座岩岛、起伏海床、14处水下岩体、90条植物叶片和一条系泊艇。系泊艇取自本项目自有CoralBay源文件，移除原码头系绳后平移，新增浮标和系泊线；原海湾源文件不改。纹理为本项目程序制作，外部照片/模型不进入资产。船舱水面遮罩使用同一份七剖面数据与新的船体位置。

所有环境共用MarineHabitat的水上/水下相机、雾、倒影缓存、暂停和减弱动态；BayHabitat保留海湾鱼群扩展及现有prefab GUID。切换时停用并销毁旧实例，只创建当前环境；Unity资源缓存和实际内存仍需设备测量。第三海域继续为样板。

源文件初次验证发现最低LOD叶片被通用简化破坏；改为沿同一曲线/封闭截面重采样后修复开放边。再复核出8片最低LOD朝向反转，已在生成器内纠正，保存源文件独立验证通过。体积改用局部坐标双精度，保留世界坐标单精度诊断值；验证器不修补候选。所有失败回执保留。

第二轮把旧圆石岛换为延伸到海床下的岩岛，移远岛体、去除石纹规则棋盘噪声并增加土层材质。保存源文件的三LOD、三座岛各五处共45处剖面，分别读取顶面、底面和海床，均证明岛体穿过实际海床；不是仅检查生成器公式。源几何通过不代表形态已经拟真。

当前Editor Metal离屏八图已逐张审阅。首次/重复RGB差为0，倒影方差与波纹变化检查通过，倒影缓存禁用后释放。水上/水下/船只视角可读；岛体仍像规整圆锥，绿土与石壁边界生硬，石头及叶片重复明显，海床层次不足。此候选保持美术PARTIAL，不能以PBR/LOD文件齐全宣称拟真成品。工作室使用独立Cycles光照，不等于运行时画面。

玩家窗口、科学/用户美术和iPhone/iPad验收仍需分别完成。当前Mac经CUA确认仍锁定，未盲目启动原生截图任务。当前TestFlight与本地iPhone安装的0.1.0 (4)/ee7ba50均不含这轮变化。

50项Editor与10项无画面PlayMode回归通过。新交互测试三轮往返近海、海湾和陆坡，核对只有当前环境实例、海湾鱼群恢复、陆坡样板雾色、水上/水下/换角、暂停/减弱动态，以及生产记录放流与重新读档。首次测试把实例名误断言为构造器名字，实际Unity保存为资源文件名，已改为检查环境类型/唯一性后通过；不为通过测试更改产品名字。它通过UI事件和规则自动控线，不代表真实触控或20次实际UI试玩。
