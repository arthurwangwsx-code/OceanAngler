# 拟真 3D 与资产制作标准

## 视觉方向
明亮的自然海洋，真实鱼体比例和游动节律，温暖木质甲板、磨砂金属卷线器、清晰水面。海湾青蓝/沙金，近海深蓝/银灰，陆坡靛蓝/暖探灯；避免深黑恐怖氛围。参考游戏仅用于分析，不提取模型、贴图、UI 或商标。

## 每条鱼的完整交付
必须包含参考板（正/侧/俯与授权来源）、Blender 源文件、干净 UV、PBR baseColor/normal/roughness/必要遮罩、可动骨骼、LOD0/1/2、简化碰撞、Unity prefab、转台预览、许可证记录。
解剖要求：体型、口部、鳃盖、眼睛、背/胸/腹/臀/尾鳍位置、物种特征纹理、鳞片尺度正确；不能同一椭球换色冒充不同鱼种。近景不能看到破面、眼睛漂浮、鳍根断裂或镜像文字。候选预算 LOD0 8k–25k 三角面，英雄鱼最多 40k，LOD1 40%、LOD2 15%；最终预算以真机为准。
纹理通常 1k，展示英雄鱼允许 2k；鱼鳞用法线与粗糙度，不把每片鳞片建成几何。透明鳍控制层数，金属度按生物表面处理，不做铬金属塑料鱼。

动画至少 idle/swim/turn/burst/bite/hooked/release 七种语义；可用少量关键动画 + 程序弯曲组合，但需验证尾鳍摆动、转弯和鱼线连接，动画速度随游速变化。水下群游与上钩鱼共用同一物种 prefab 和尺寸尺度。

## 场景与钓具
码头、船、礁石、沙地、珊瑚和海草形成可读层次；烘焙静态光照，限定实时阴影距离，假焦散与粒子海雪提供深度。水面需岸边过渡、波纹、反射和透射的成本可控近似；水下需要雾、颜色吸收、局部光束和浮游颗粒。不能把蓝平面算完整海洋效果。
竿有分段弯曲或骨骼约束，导环/鱼线/拟饵位置一致，卷线器摇柄可转、线杯行为协调；第一人称手部另做 rig 或在 P0 明确省略，正式版不能用 UI 图标代替钓具模型。

## 生产流程
概念与科学参考 → 授权筛选 → 高模/低模 → UV/PBR 烘焙 → rig/动画 → Blender 检查 → FBX/glTF 中间产物 → Unity 导入 preset → prefab 验证 → 三种光照转台 → 运行时近景 → 真机性能 → 人工验收。
AI 图片只辅助概念，AI 生成 3D 必须经过拓扑、权重、UV、来源与生物特征修整。当前不自动购买资产或上传私人素材到外部生成服务。

## 资产许可与开源
asset-manifest.json 逐项记录 id、作者、来源 URL、获取日、许可证、可修改/随包分发/源码再分发、原件 SHA256、修改说明和审核状态。优先原创 CC0 或明确允许源码再分发的资产；CC-BY 保留署名。商业商店 EULA 不能默认等同 MIT，禁止将原始付费模型上传公开仓库。受限资产放私有包并提供可再分发替代，公开工程必须能用替代资产启动。

## 美术验收出口
A0 轮廓原型：仅验功能；A1 完整模型：全部部位/PBR/动画/LOD；A2 场景观感：白天、阴影、水下、近景无明显缺陷；A3 真机：iPhone/iPad 画面与帧耗验收。至少对首条英雄鱼和第一套钓具制作 360° 转台和四角截图，经用户审阅后批量生产其余物种。功能 PASS 不能覆盖 A1–A3。资产登记为空即代表尚无成品模型。
