# 近海地形与材质迭代

本轮继续REQ-06，候选实现与成品验收分开。手机与TestFlight仍为冻结a6bcf8e的build 5；以下为后续开发源码，不推定已经更新到设备。完整产品与美术A1–A3仍PARTIAL。

旧岛体每层轮廓不断收小，远景像圆锥，顶部按面切换绿土材质形成硬帽。本轮改为封闭高度场、偏置山脊与较宽的起伏顶部，保留延伸到海床下的实体基座。土层覆盖按顶点连续混合两组原创PBR材质，不再逐面切换材质。三档LOD均保存有限、连续权重；保存源检查仍逐实体核对封闭/朝向，并读取45处实际基座/海床剖面。

首次近景显示按面选择投影方向会产生三角形纹理接缝，已改为运行时世界空间三轴混合采样，法线以实际表面方向重建；平坦法线输入保持几何法线。三个渲染pass覆盖前向PBR、投射阴影和深度。引用Unity包头文件，不复制分发引擎实现。两组颜色/法线/金属/光滑度采样在三轴上混合，最坏18次贴图采样；实际iPhone/iPad成本尚未测量，不能以桌面图证明预算合格。

Blender预览使用世界盒式投影和凹凸近似，运行时使用上述三轴法线；两者灯光和材质求值不同，不作为逐像素匹配。工作室曝光降低1.1档，仍需继续校准。源LOD0合计61810三角面（含独立水面），高于旧候选42364；不是全游戏帧几何预算。

GPU夹具新增三次静态绘制、岩壁近景和水下岸脚，检查真实近处阴影、投影和基座衔接，保留水面/水下/船只/波纹/无水/倒影控制及所有材质的shader支持/错误检查。早期4×MSAA采样出现21像素、最大1/255差异；不重复设置相机的对照仍复现，单采样对照为0。尝试显式resolve产生错误首图，已否决并撤回；相机优化尝试也已撤回。不降低游戏4×MSAA，不放宽逐像素门槛，PARTIAL回执继续返回非零退出码。三轴实现曾有两次独立4×MSAA运行的三图RGB差均0，但最新范围回执再次出现12像素、最大1/255差异，最终保留PARTIAL。根因尚未证明，不保证任意设备或独立Editor进程逐位一致。

岛体大轮廓、土层边界和近景投影已有改善；细裂纹仍有明显程序纹理感，崖面偏平滑，岩体/叶片重复、海床层次与水边细节仍需精修。它不能代表完整拟真美术通过。当前CUA仍确认Mac锁定，没有本轮玩家窗口；用户/科学、儿童/家长、iPhone/iPad画面/触控及20分钟资格仍未验。第一条英雄鱼/钓组用户审阅门保持，尚不批量生产其他鱼种。
