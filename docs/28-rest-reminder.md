# 休息提醒与沉浸菜单

依据产品方案的每15分钟温和提醒和沉浸界面要求，补齐当前提醒的确认路径。提醒仍只在未暂停的游戏时间累计到900秒后出现；不自动暂停、不改变奖励、不丢弃鱼获、不要求等待或付费。首套美术用户审阅及真机/儿童出口保持独立。

准备抛竿时借用现有边缘提示，不新增HUD或常驻按钮。等待咬钩时仍遵守安静提示淡出，不因待休息标记让无关提示常驻。提竿、控线和收鱼不被休息提示覆盖。

打开暂停或首页时，原有底部说明展示“和家人休息一下，准备好再继续。”，原有继续按钮改为“休息好了，继续”。只有主动点击该按钮才清除提醒并重新开始下一段900秒计时。查看设置、图鉴、准备或其他页面本身不表示休息完成；不强制判断用户是否真的休息。未到提醒时继续沿用普通“继续探索”，不重置累计时间。
