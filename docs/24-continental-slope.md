# 陆坡海域制作约束

对应REQ-06，替换第三海域的运行时基础几何。沉浸游玩、分层入口和已保存进度保持现有共享流程；不改遭遇概率、奖励或存档格式。英雄鱼/钓组样板仍待用户审阅，本轮制作环境与研究设备，不批量生产其他目录物种。

场景为艺术化的陆坡峡谷样段：两侧侵蚀岩壁、坡脚碎石、中央软沉积通道、海雪和一台带暖灯的研究潜器。水面为开阔外海及本项目自有小艇的测量用途改装。它不是某个真实地点的重建，不声称目录鱼种在同一生态群落共存。深水照明兼顾儿童可读性，不照搬浅海海草/珊瑚礁。

参考资料仅用于形态和生态约束，不下载或转用照片/模型/贴图：

- [NOAA：深海峡谷、陆坡和海山](https://sanctuaries.noaa.gov/visit/ecosystems/deep-sea.html)：岩壁/陡坡与深海栖息环境参考。
- [NOAA NCCOS：深海珊瑚](https://coastalscience.noaa.gov/science-areas/coral-ecosystem/deep-sea-corals/)：深水光照与和浅海生态的区别；不据此认定场景内的物种组成。

独立Blender源工程、FBX、原创PBR、三LOD与Unity prefab必须实际生成；保存源文件独立验证封闭/朝向、UV/依赖、LOD、沉积通道和设备位置。潜器悬停于侵蚀岩阶上方，检查实际网格间隙。水面高度200米、常用钓鱼相机约1.25米为本地场景坐标，提供深水水柱；不把坐标设置当作完整水压、光学或生态模拟。

共享水面要使用实际海平面及船舱剖面，水上/水下照明切换必须可逆，离开海域要恢复场景灯光。检查鱼获、放流及保护观察的现有运动体积，不能让岩壁或研究设备进入活动空间。新界面海域鉴赏共用入口，禁止另做大块游玩HUD。

源预览、Editor GPU和实际Player/模拟器分别取证；三LOD和PBR齐全不等于拟真美术合格。用户/科学、美术A1–A3及真实双设备性能仍是独立出口。
