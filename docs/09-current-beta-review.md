# 首批候选的设备复核

适用于 OceanAngler 0.1.0 (2)，冻结源码2971b116db9b5dd18dd59ce837d8a2e8625875e9，最低iOS/iPadOS 17。Apple处理、内部组和邀请状态以[构建回执](../reports/testflight-0.1.0-2.json)为准。只有首条蓝鳍鲹、首套纺车钓组和珊瑚海湾是独立源资产候选，其余模型仍是prototype。

## 首轮操作

1. 在TestFlight确认安装的是0.1.0 (2)，记录设备型号、系统版本、安装来源和能否进入钓鱼主界面。API中可分发不等于已安装。
2. 在“出海”打开“海域与装备”，进入“看看海湾”；观察码头、船、海岸和珊瑚是否清楚完整。使用“回到水面”与“潜入水下”切换，检查水面边界、穿模、黑面和闪烁。
3. 返回钓鱼，应保持暂停；主动点击“继续探索”才恢复。观察期间不应继续咬钩或自动收线。
4. 打开“钓具”→“观察入门钓组”，使用“旋转钓组”“近看卷线器”和“查看全竿”，检查竿、九个导环、卷线器、线和拟饵。点击“试摇卷线器”，观察摇柄、转子、线杯；停止演示和离开页面后动作应停止。
5. 返回出海并继续，完成蓄力抛竿、等待咬钩、提竿、按住收线、松手降张力及“记录并放流”。检查积分与图鉴有记录。
6. 战斗时按住收线，再切到钓具或海湾观察；返回后应保持暂停，点继续也不能自行收线。再主动按住才收线。
7. 完成一次鱼获后，退到后台再恢复，并重新打开应用。核对鱼获、积分、装备与任务进度；不要为了测试清除个人存档。

每项记录PASS、PARTIAL或FAIL及具体发生位置，未做写NOT_RUN。画面问题同时说明水上/水下、观察/钓鱼及操作步骤；设备标识、原始截图与日志留在本机忽略目录，不上传公开仓库。

## 独立验收

首轮操作通过仍不能替代以下完整验收：iPhone和iPad分别连续20分钟的帧耗、内存、温升、安全区、旋转与触控；界面连续20次钓鱼无卡死；首次儿童/家长试玩及首鱼3分钟观察；英雄鱼、完整钓具与环境的A1–A3人工美术审阅。源模型工作室图、无画面测试、Mac运行和手机实拍分别留证。

反馈至少包含：构建号、设备/系统、安装启动结果、已做步骤及异常复现方法。未看到实际画面与真实参与者反馈前，不批量宣称其余鱼类、钓具和海域已完成。
