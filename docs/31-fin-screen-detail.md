# 屏幕尺寸与英雄鱼远距鳍条

对应REQ-05/2.5/2.7，继续首条英雄鱼样板。实际游玩图的胸鳍出现规则细点，不能以“近景正常”宣称全部画面合格。

在1440×960、Medium、Metal、Half HDR、4×MSAA的隔离导入场景中，补充鱼宽占视口16%/32%的对照。旧模型在16%下关闭鳍法线仅改变9像素，关闭鳍条阴影改变5像素，隐藏鳍条前向绘制改变673像素；选定原图的细点随鳍条前向绘制消失。降低鳍条光滑度或关闭高光仍有残留。这是该受控姿态下的诊断，不能据此断言所有游戏画面的全部噪点都只有同一原因。

制作方案保留近景LOD0的所有实体鳍条、几何、UV、权重与原贴图。LOD1/2重建相同轮廓和闭合渐薄膜面，保留每片鳍两根轮廓鳍条，内侧细节由现有膜面分条UV/PBR及纹理过滤表达；保留的不透明鳍条仍写深度、投射阴影，正式材质不关闭法线、阴影、高光或膜面。三档24664/9864/3698预算保持不变。

调整实际LOD阈值，让低于像素尺寸的内部小圆柱在远距进入相应表示，近景继续使用完整几何。Unity的LOD阈值按屏幕高度比例生效，组的Object Size也参与计算；不能把鱼宽比例直接当作阈值。依据[Unity 6.3 LOD Group说明](https://docs.unity.com/en-us/engine/6000.3/manual/analysis/graphics-performance-profiling/lod/lod-group/class-lodgroup)，以实际自动选择图与强制相应LOD的逐像素对照验证，而不只检查预期阈值。

源检查读取实际保存模型，复核整个LOD0身份、远距16根实体鳍条与原完整鳍条的几何/权重对应、72处薄壁及七动作；Editor检查实际导入的材质与机构，GPU分别检查近景、16%/32%、自动远近选择及恢复重复。最终仍需新冻结原生包复核实际游玩；自动化/源检查不代表儿童、科学、用户或A1–A3美术合格。完整产品保持PARTIAL，不批量制作其他物种，不新增HUD或改变积分、存档及TestFlight冻结包。
