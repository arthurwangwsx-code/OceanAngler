# 海湾海草斑块候选

REQ-05/06及任务4.8，实施IN_PROGRESS，成品美术未验。当前海草虽然随机散布，但每丛5–9片叶共用一个根点，尖刺状扇形重复明显。本次先改变海草的源几何和布局；礁石、珊瑚、地形、码头、小艇及相机不做布局修改，保持捕鱼中心留白。

从14个候选斑块中心筛选可种植位置，形成260个分散草株，每株3–5片带状弯叶；实际有草株的斑块数写入构建记录。叶根分散、叶长/宽度/弯曲/轻微扭转变化，同株及同斑块的弯向相关，避免每株向四周等价辐射。保留左右沙地间的中央钓鱼通道，避开已有岩石脚印及露出水面的岸地。草根略埋入海床，检查实际保存的地形网格，不能只检查生成公式。

参考依据只用于形态方向：[NOAA海草床说明](https://floridakeys.noaa.gov/plants/seagrass.html)介绍叶片由沉积物下的根茎生长并形成草床；[佛罗里达自然历史博物馆](https://www.floridamuseum.ufl.edu/southflorida/habitats/seagrasses/)介绍草株与叶片、根茎扩展的关系。本候选没有指定植物物种、地域组合或完成科学审阅；不复制参考照片为贴图，也不据此宣称当前布局符合真实生态。

使用独立固定随机源；不增加运行时散布/每帧分配、材质、透明层、额外组件或HUD。三LOD继续由保存的源模型导出，不允许在Unity手工偏移掩盖源文件问题。新LOD0必须不超过原18390三角面；全部非海草源网格/UV/材质槽/标尺变换和既有PNG、其他模型文件需比对保持。

先做源几何/LOD/根部与通道检查，再导入Unity，使用相同三海域姿态和光照查看首绘/重绘以及修改前后原图。视图外或低LOD的根部、细叶闪烁、光照和材质仍须实际审阅。之后冻结新原生包检查双端，而不是复用旧模拟器App证明新模型；物理设备成本与人工美术另验。用户对首套鱼/钓组方向的审阅与其他11鱼种成品制作门保持原状。
