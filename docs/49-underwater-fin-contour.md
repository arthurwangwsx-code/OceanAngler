# 水下鳍膜轮廓修正

## 问题与证据

原生图鉴中，蓝鳍鲹两片背鳍的鳍膜在同一水平位置缺失，不透明鳍条仍伸出，形成细长尖线。全部鳍条的保存源模型变形诊断，以及隔离环境中的真实导入模型画面，没有显示同等程度的几何脱离。随后在实际 CoralBay 场景复现；只改变水面的绘制次序，保持鱼体、动作、相机、光照和鳍材质，完整背鳍重新出现。

海域水面很大，透明物体按对象排序时，水面可被排在实际更近的透明鳍膜之后；不透明鳍条已写入深度，因此产生不一致的遮挡。此处因果判断来自本项目的场景消融。Unity 的透明排序规则见[SortingCriteria 官方说明](https://docs.unity3d.com/6000.0/Documentation/ScriptReference/Rendering.SortingCriteria.html)；当前导入的 URP `DrawObjectsPass` 也使用 `CommonTransparent`。

## 实现边界

`MarineHabitat.Present` 设置最终相机后，水下让水面比原始顺序提前一层；回到水面时恢复原始值，组件停用也恢复。三个海域共享此实现。不复制材质，不改材质队列，不关水面、不移除鳍条、不改鱼体或扩大图鉴画框。

新增诊断使用真实 prefab、运行时七动作中的 swim 片段、三档 LOD、两个方向及四个相位，保留生产首绘和重复绘制。不透明、双面、无鳍条、水面原顺序／提前／隐藏均为独立诊断对照，不能作为生产截图冒充结果。显示稳定性保持逐像素零差异要求；失败必须保留。

本人模式增加显式 QA 开关：通过现有页面逐个选择三个海域，分别查看水面、水下及暂停的四向蓝鳍鲹，保持零积分、零鱼获。它不增加常驻入口或遮挡。正常与测试存档、模式选择、关闭与失败保护继续按开发者模式规范验收。
