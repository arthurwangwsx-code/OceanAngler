# 图鉴动画几何包络

承接40与REQ-05/08。当前最大正面只利用可用轴约51%–57%，仍未达到清晰查看完整模型的目标。本轮替换粗略单包围盒，保留实际UI空白区、同帧旋转、0.7–1.5缩放、暂停、返回相机和旧进度保护。

从正式两套原创导入模型与十种现有程序样板采集三LOD/实体/鳍条的实际变形网格。编辑器按游动周期65姿态及原创鱼的idle采样生成沿鱼长32段的稳定包络，各段加小量几何容差；数据标记源文件摘要与采样范围。运行时只读取分段数据和缓存投影，不逐帧采样或烘焙动画。未登记的新模型保留保守回退，但当前12种必须有与源一致的数据。

最大正面投影在可用宽/高中的较大比值目标至少75%，两套原创鱼在双端目标至少78%；完整身体仍需保持在真实控件反推的区域内，且查看不写进度。旋转时不超过默认正面尺寸，避免薄边朝向被自动放大成巨物。用独立于制作用采样的中间姿态、全周角度、缩放上下限、自然动画与原生图片核对；不能以单纯加大比例或放宽越界条件通过。

生成包络不会让现有样板自动成为成品模型。拟真美术、科学/用户A1–A3、儿童和真实设备等仍独立开放。实现IN_PROGRESS，验收NOT_RUN，apply不勾选。
